# Melian research notes

What was found when a question needed looking into, one file per topic, with its sources. A decision file in [decisions/](../decisions/) cites the research it rests on, so a reviewer can check the evidence as well as the choice.

Research is input to decisions. A note says what was found and where; it never states a decision. A finding that changes the design goes into [design.md](../design.md) and a decision file, which link back here.

Name a file `YYYY-MM-DD-<slug>.md`, dated the day the research was done, as the decision log is. A new note is a new file. When later research overturns a note, add a note that says so and links the one it corrects, rather than editing it.

Notes on other people's work describe it and cite it. Material read under a private licence or with private access is described, never quoted, and the repository it came from is not named.
