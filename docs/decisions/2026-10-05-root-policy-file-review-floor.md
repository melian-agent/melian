# The root melian.yaml may tighten the review of itself, never loosen it

Choice: policy-change-review judges a change to the root `melian.yaml` under the root's own configuration, with the defaults as a floor. The guardrail stays on for that file. Its `severity` and `analyserSeverity` are each the stricter of the root's and the default's. Under the policy source the host chose, a change to the root raises at least the default `P2` notice. A root that sets `P1` blocks on its own edit. A pull-request review reads the base, so a head cannot hide a change to its own root policy. A checked-out range reads the working tree by design, because its author is the maintainer. A nested `melian.yaml` is still judged under the configuration of the directory above it, as [the lens-with-no-paths decision](2026-10-05-lens-with-no-paths.md) records. What the root sets still governs every path beneath it. On a working-tree review, the root's configuration includes the maintainer's `melian.local.yaml`, merged last as always. The floor applies after it, so that file too can tighten the review of the root but not loosen it. A policy-change-review finding on any `melian.yaml` resolves under the configuration that judged it, not the file's own. It never resolves below `acknowledge`.

Why: the root has no directory above it, so it was judged under its own settings, and a root that set `guardrails.policy-change-review.enabled: false` hid every later edit to itself. A pull request could then rewrite the repository's lens paths or guardrail rules with no maintainer asked to read the change. Judging the root under the built-in defaults alone closed that gap but opened another: a maintainer who raised the severity to `P1` so that policy edits block found an edit to the root itself only acknowledged at `P2`. A floor keeps both: no configuration file switches off or softens the review of itself, and a stricter choice still holds. The resolution needs the same floor: a root that maps `P2` to `silent` would otherwise pass a change to itself with no notice, though the guardrail reported it.
