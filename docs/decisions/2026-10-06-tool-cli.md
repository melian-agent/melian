# Tool readiness from the CLI

Use `melian tools` to list Melian's bundled manifest pins and local readiness. Use `melian tools fetch <name>` to materialise one verified executable and print its path. Neither command executes it. Fetch retains the cache's digest checks and repair rule.

Doctor re-hashes every cached pin without downloading. A missing executable is a warning; a mismatch fails doctor. The host's environment sets the cache location through the existing state-directory rule. Repository content never supplies a manifest.

The spike's 2.95 MB entry does not justify a prune command. Search budgeting, test execution and verifier use of callers stay deferred. Review and findings already expose coverage identities in their JSON records.
