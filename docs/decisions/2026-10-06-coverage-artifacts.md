# Coverage artifacts

Graph, review and test coverage are validated classes over stored JSON. Each hashes its content. Coverage files sit beside the graph under its tree/version/binary/policy key, so no artifact reaches the state branch. Publication renames a complete temporary file; unreadable data is absent.

Review coverage counts successful numbered read output and delivered search matches from durable history, including entries before compaction. It records changed hunks touched by reads. Supplied compiler declarations give enclosing functions; absent declaration ranges do not become invented coverage. Base reads remain distinct from head reads.

Test coverage records unavailable pending milestone 3 container isolation. Neither the spike nor a static check executes the head’s tests. Static snapshot records hold that content ID and a measured graph-coverage ID when present. Transcript capture will attach review identities through the small lens integration seam.
