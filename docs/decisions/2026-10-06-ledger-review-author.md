# Ledger ownership from the posted review

Choice: ledger discovery requires an author from the token login, recorded ledger, or Melian's posted or recorded review ID on the same pull request. Publication supplies that review ID. The provider reads its author when the other sources are absent. A signed body alone never authorises adopting a comment.

Problem: creation time does not prove who published a signed ledger. Another commenter can edit their older comment to copy its whole public body.

Example: a stranger's comment from December acquires the signed body of Melian's January ledger. Sorting by creation time picks the stranger. Matching the posted review's author excludes that comment.

Without any author source, publication creates a fresh ledger. A crash between create and record under an installation token then leaves an orphan to delete by hand. Normal publication has a review ID before writing the ledger, so recovery can use that review's author.
