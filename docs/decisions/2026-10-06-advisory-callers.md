# Advisory callers and transcript identities

Use a verified cached graph for advisory callers after deterministic checks. A missing executable or snapshot, a failed query or a timeout leaves the lens running with a note. Static Enola retains its closed failure rule. Caller input cannot make a failed static check clean.

Query full fact names scoped by file, depth 1 and at most 50 nodes. Reject fuzzy target selection and directory-scoped name collisions. Facts have declaration starts but no ends. Select the declaration preceding each changed hunk and declarations in the hunk, using the next start as a conservative boundary. Extra candidates are acceptable; an absent candidate proves nothing.

Quote every candidate under the review’s existing nonce through the Lens instructions seam. Limit each symbol to 40 callers and 4 KiB, with cut counts. Bound the whole section to 64 KiB and queries to 128 symbols or the tool’s time budget. These extra limits bound wide changes; they do not budget search. Confirm a candidate through read_file before citing affected evidence.

Completed lens task receipts retain each conversation ID as an optional field. An attached review reads those conversations with the stored nonce, including earlier failover and escalation reads. Older receipts without the field confer no transcript coverage. The change is backwards compatible and needs no migration. Lens records hold the captured review-coverage ID beside graph and unavailable test coverage when present. Missing declaration ranges confer no enclosing-function coverage.

Coverage writes take the reader’s 16 MiB bound. An oversized table fails capture with a note rather than returning an ID for an artifact the cache cannot read.
