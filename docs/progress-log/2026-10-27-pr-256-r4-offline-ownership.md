# Offline export keeps later stored-owned comparisons

[Pull request #256](https://github.com/melian-agent/melian/pull/256), implementing [issue #231](https://github.com/melian-agent/melian/issues/231), now shares core's tri-state stored-ownership query between classification and export. Offline export combines saved members with later conclusive ownership, retains eligible raw records, and refuses changed foreign ownership before touching output. The saved snapshot and history remain unchanged; added records receive a stderr notice and a Markdown as-of note without invented membership numbers. Real scripted CLI regressions reproduce the former loss after two reviews and imports, preserve round 2's adjudication history, and cover both formats and destinations with no-snapshot controls. Class tests cover ownership precedence, unavailable members, unknown candidates, raw-only additions, collisions and existing control escaping. The [amendment](../decisions/2026-10-27-offline-export-stored-ownership.md) records this offline scope without changing storage or build-4 writes.
