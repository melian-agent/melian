[Pull request #221](https://github.com/melian-agent/melian/pull/221) builds the ledger's run details from the review's stage telemetry, as [issue #213](https://github.com/melian-agent/melian/issues/213) asked. `melian publish` passes the run to the publish task, now version 7. The details fold under the run's summary line: time, tokens with their cache share, cost and each model with its reasoning level. Inside, a table gives each stage a row, with a budget only near or past its limit and a note on what `budget.tokens` counts. The standards appear once. Tokens, cost and time format the same way in the ledger and in `melian telemetry`, which opens with the same summary line. [The decision](../decisions/2026-10-25-run-details-from-telemetry.md) records the ruling.
