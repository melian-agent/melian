# The conventions lens's findings budget is 16

The maintainer raised `lens.conventions`'s committed findings budget from 8 to 16 on 2026-11-09. On large pull requests the lens filled its budget with P3 writing-rule breaches before it finished, so the round read not reviewed. That happened on rounds two and three of [pull request #341](https://github.com/melian-agent/melian/pull/341). A pull request's round reads lens budgets from its base, so no local override can raise it for one round. Policy only; no code changed.
