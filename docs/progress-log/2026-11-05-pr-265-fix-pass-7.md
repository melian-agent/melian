# Timeline fix pass 7: one reading of a comment, a cost at zero minutes, and the span's end

For [pull request #265](https://github.com/melian-agent/melian/pull/265), fix pass 7 closes the three P2s Melian's round 6 found at `97000ce2`. Each fix started from a test built from its failure scenario.

- `0284f2a7`: `Claim:` and `Fix pass` were matched on a comment's trimmed raw text, so an indented `    Claim: example only`, which Markdown reads as a code block, counted as a claim. It was the second case of the class the `Timing:` fix closed. Before the fix, the test's comments gave three marker rows; after it, two.
