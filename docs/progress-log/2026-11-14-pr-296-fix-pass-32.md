For [pull request #296](https://github.com/melian-agent/melian/pull/296), fix pass 32 stops a probing run being reused under another CPU architecture or Node version, and names its host by one value. It also merges `main` again. The fix began with failing tests.

- After pass 31, a probing run's key named the host's platform and the sandbox, but not the CPU architecture or the version of the Node that runs each probe (`327e7395`). So a passing probe from darwin-arm64 under Node 24 was reused on darwin-x64 under Node 22. The key now holds one `ProbingHost` value, built by `probingHost` from the sandbox and from the Node that runs the probe, which is this process's own. A probe refuses to open on a host that differs from its own in any part. Codex's adversarial review at `70104721` raised it. It was the second review in a row to find a missing host fact, so I raised the class with the coordinator, who chose one host value, as [issue #288](https://github.com/melian-agent/melian/issues/288#issuecomment-6869059158) records.
  - A second review under another architecture or another Node version reused the first before the fix and runs its probes again after; one on the same host still reuses it.
  - A probe whose environment names another architecture or Node version ran before the fix and is refused after.
  - Any Node upgrade or change of host therefore runs a probing level once more, on purpose.
- [The identity guideline](../guidelines/identity.md)'s row for the lens-task attach key now lists what about the host is left out on purpose, and why: the operating system's release, the CPU's model, the sandbox's own version, the host's locale and clock, and what the system's programs and the read paths hold.
- `main` merged in at `70104721` again, with no conflict, bringing [pull request #412](https://github.com/melian-agent/melian/pull/412)'s new warning line for the decision index.

[The inventory](2026-11-14-pr-296-fix-pass-32-mutants.json) lists the pass's 7 mutants: 6 killed, each by its named test alone, and 1 equivalent, the rendering sample's host, which no rendering reads.
