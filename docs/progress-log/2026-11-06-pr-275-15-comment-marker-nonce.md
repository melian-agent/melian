The report job now finds its own comment by a marker no other workflow can forge, in fix pass 2 of [pull request #275](https://github.com/melian-agent/melian/pull/275). Melian's round found that the marker named only the run's ID, which is public, and every workflow's token posts as `github-actions[bot]`. Another workflow could post `<!-- melian-round run:N -->` first, and the report job would then overwrite that comment with the round's result. A failing test first took the forged comment for the run's own. The round job now draws a 32-digit hex nonce with `openssl rand -hex 16` and hands it to the report job as a job output, which a rerun keeps. The marker carries it, and `ownComment` refuses a run without one rather than match a marker anyone could write.
