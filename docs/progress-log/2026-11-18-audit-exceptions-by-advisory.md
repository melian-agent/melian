# The gate's audit takes exceptions by advisory

Since 2026-11-17 `npm run check` failed on `main`, because GHSA-fc5q-39xc-vjpf, a high-severity ReDoS in picomatch, covers every released version and so no upgrade could clear `npm audit --audit-level=high`. The maintainer ruled on 2026-11-18, in the coordinator session, that a script replace the bare audit, and [the decision](../decisions/2026-11-18-audit-exceptions-by-advisory.md) records its behaviour. `scripts/check-audit.mjs` blocks every advisory at high or above in `npm audit --include=dev --json` unless `.audit-exceptions.json` names its GHSA ID, and blocks every one in `npm audit --omit=dev --json` whatever the file says. The file holds GHSA-fc5q-39xc-vjpf alone. `scripts/check-audit.test.mjs` holds 33 tests: the decision against reports npm 11.16.0 wrote on 2026-11-18 and reports built in each test, and the script itself run against a fake npm that answers only those two audits. They failed before the script existed and pass at the head. The script exits 0 on the tree at the head and 1 with the exception removed. The maintainer fast-tracked the change on 2026-11-18, in the coordinator session, so no mutant was run by hand. `melian mutants list origin/main...99f52f8e` lists 153 generated mutants of `scripts/check-audit.mjs`, all of them unproven, and none of its guards is proved by a recorded mutant run.
