Melian's twelfth round on [pull request #89](https://github.com/melian-agent/melian/pull/89) confirmed one defect. `ReviewTranscript` credited a `read_file` result only when the call's raw `path` was an exact member of the changed paths, but the tool normalises the path before reading. A read of `./src/a.ts` or `docs/../src/a.ts` delivered numbered lines and was recorded as not read. The transcript now canonicalises the path with core's `repositoryPath` and drops a call whose path escapes the repository. The core and pipeline guidelines now list `static.enola` among the deterministic checks, the CLI guideline names the `unavailable` readiness state, and the offline-metadata decision says which part of the tool-manifest decision it supersedes.
