For [pull request #296](https://github.com/melian-agent/melian/pull/296), Codex's eleventh adversarial review, at `ea767a4c`, found that the 48-probe limit counted stored results, and a refused probe stores none. So a prober could call `run_probe` without end while every call was refused after its work. That is a gap in fix pass 8's limit, the class the maintainer ruled on 2026-11-09, so it is fixed in that pass's terms. Each call's ID is now recorded before its probe starts, and the limit counts those attempts (`462b2573`). A test whose sandbox refuses every probe reached it again past the limit before the fix, and refuses there without starting it after. [The inventory](2026-11-09-pr-296-fix-pass-10-mutants.json) lists the fix's 14 mutants, each killed by its named test alone. The seeded-default mutant needed the limit lowered to one (`8de58e52`).
