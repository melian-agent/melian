# Pi 1.1.0 upgrade ([pull request #136](https://github.com/melian-agent/melian/pull/136))

[Pull request #136](https://github.com/melian-agent/melian/pull/136) takes `@earendil-works/pi-ai`, `pi-durable` and `chord` from 1.0.0 to 1.1.0, split out of [pull request #135](https://github.com/melian-agent/melian/pull/135) so the upgrade is reviewed alone.

- The lockfile moves six packages: the three above, `pi-telemetry` 1.0.0 to 1.2.0, `@anthropic-ai/sdk` 0.124.0 to 0.129.0 and `@babel/runtime` 7.29.7 to 7.29.10.
- One fix: two static-check tests narrow `Shell.exec`'s command to a string, since 1.0.3 also accepts an argv array. No behaviour changed.
- 1.1.0 puts a conversation's first system message ahead of the input. Every live lens sees a new prompt layout. No fake-model test measures it, so a live golden run on the head comes before the queue.
- The plan is unchanged.
- Pi 1.1.0 renames the Azure provider from `azure-openai-responses` to `azure` (found by the Codex adversarial review). A stored credential for the old ID fails with `unknownProvider`. [The decision](../decisions/2026-10-17-no-alias-for-renamed-pi-providers.md) adds no alias.
