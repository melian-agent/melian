A builder can now start its own Melian round on GitHub Actions, in [pull request #275](https://github.com/melian-agent/melian/pull/275) for [issue #270](https://github.com/melian-agent/melian/issues/270). Rounds ran only on the coordinator's machine, where the provider credentials are, so every fix pass waited there. `.github/workflows/melian-round.yml` runs on `workflow_dispatch` with a pull request number. A gate job refuses a starter without write, maintain or admin permission and a head outside this repository, so a fork's head never runs with secrets. The round job checks out the head with full history, runs `npm ci --ignore-scripts`, raises the lens budgets with `scripts/round-budgets.mjs` as [AGENTS.md](../../AGENTS.md#three-reviews-before-ready) sets them, and runs `melian review origin/<base>...HEAD` with the head's own build; the logins reach only that step. The whole output is the job summary and the `melian-round-<attempt>` artefact. A report job with no secrets comments, through `scripts/round-comment.mjs`, the run's link, the `Verdict:` line, the checks that did not run, and every block and acknowledge finding, all inside one code fence no backtick run in the head's text can close. It never publishes or dismisses, and its store is thrown away. The maintainer ruled on the credentials: the job reads `CLAUDE_CODE_OAUTH_TOKEN`, which Melian takes itself, and `CODEX_AUTH_B64`, the Codex login cloud sessions receive. `scripts/round-codex-token.mjs` takes the login's access token alone, and a user-level secrets file names it by variable as an `openai-codex` bearer credential, so the committed routes hold and nothing refreshes the login. A `melian doctor` run on this session's own login routed every tier to its committed Codex model. The comment also quotes the checks that left the committed routes, so a round on an expired token says so. The cost question is open on the issue. GitHub dispatches a workflow only from the default branch's copy, so the first recorded run follows the merge and gets its own entry.
