The documents now say what the `melian round` workflow does not do, in fix pass 2 of [pull request #275](https://github.com/melian-agent/melian/pull/275). Melian's round on `3b3351c` raised three findings against documented decisions. `docs/design.md` and `AGENTS.md` said each round runs from the branch's own build, while the workflow runs the default branch's; both now say so, and that a pull request changing Melian's review code also needs a host round from its own build. The workflow's comment says that "Re-run all jobs" runs a new round under a new nonce, which posts its own comment, while a rerun of the report job alone updates the comment it posted. No test covers these; they change prose and a workflow comment.
