[Pull request #74](https://github.com/melian-agent/melian/pull/74) adds `scripts/codex-sandboxed.sh` and `scripts/codex-seatbelt.sb`, which run a Codex task in full-access mode inside a seatbelt profile of our own. Codex's workspace-write sandbox denies every write under `.git`, so a task could not commit or fetch. The profile allows writes only to the worktree, the checkout's `.git`, scratch, temp, and the Codex, npm, and gh caches; reads and the network stay open. It is macOS only. The script no longer ends in `exec`, which skipped the trap that removes the temporary profile. `AGENTS.md` carries the Learnings entry and `README.md` the usage.
