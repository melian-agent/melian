# A probing miss scores only where trust-boundary saw its lines

[Pull request #504](https://github.com/melian-agent/melian/pull/504), for [issue #485](https://github.com/melian-agent/melian/issues/485), stops `npm run eval:probing` from scoring a miss on a file the lens never saw. Coverage held the file, but a lens prompt stops at 200 KB, so on a large range the file could fall past the cut.

Each lens stage in telemetry now records `shown`, the head paths whose diff blocks its prompt carried whole, and `read`, the head lines `read_file` delivered whole for each changed file. `Miss.unscoped` refuses a miss unless a completed, non-prober `trust-boundary` stage that covers the file saw the defect. Seeing it means one of two things: `read_file` delivered a line inside the miss's `lines`, or the prompt showed the file and a head-side hunk of the range's diff holds one of those lines. A refused miss prints as unadjudicated, with no score. `shown` is set after `lensRequest` keys the run, so no ID, fingerprint, cache or attach key changes.

Codex's adversarial review found two gaps, and each was fixed test-first with the coordinator's approval. First, the prompt's diff has no context lines, so a shown file proved nothing about its unchanged lines; 5d02855f takes the hunks from the parsed diff. Second, `read_file` cuts a line longer than its output limit and shows only its start; 38077f19 and 79363db6 mark that result with a structured `lineCut` detail, set where the tool writes its "[line cut]" text, and telemetry leaves the line out of `read`. Review coverage still counts a cut line as read; the coordinator will open that as its own issue.

The [mutant inventory](2026-11-16-pr-504-mutants.json) lists all 167 mutants of `origin/main...79363db6`, with 12 ignored by configuration. The core type change reaches 284 test files, so every claim was rerun at 79363db6 rather than a selection. Each of the 155 generated mutants ran by hand against its named test alone. 149 were killed. The other 6 are equivalent, each with its reason, and survived every candidate test file the runner tried.
