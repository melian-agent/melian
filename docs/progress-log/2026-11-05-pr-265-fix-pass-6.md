# Timeline fix pass 6: no stage table, and Timing lines from comments only

For [pull request #265](https://github.com/melian-agent/melian/pull/265), fix pass 6 applies the maintainer's ruling on Melian's round 5 at `8719be3c`. The derived stage table drew findings in four of five rounds, and round 5 added three more: a negative interval, a queue stage outliving the queue, and an issue never marked ready counting as ready from its opening. Each change started from tests that failed on the head before it and passed after.

- `284f29c0`: the stage table and the ready, claim, build, review and queue bookkeeping behind it are gone. The summary keeps the CI total and the span, which still ends at the merge, and adds one line summing every Timing item's minutes and cost, or `none`. The expected table for [pull request #256](https://github.com/melian-agent/melian/pull/256) was re-recorded from the script's output: only its summary changed, and its event and gap rows are identical. The limit that only described stages, several closing issues, is gone too.
- `9b0e68cc`: `Timing:` lines come from issue and pull request comments only, as [the timing decision](../decisions/2026-11-04-timing-line.md) says, never from the description or a review body. Before the change, a description, a review and a comment, each with a `Timing:` line, gave three Timing rows; after it, one. A header limit records that a `Timing:` line counts whoever wrote the comment.

The script's known limits now read:

- commits a force-push replaced appear only as the force-push row's tips;
- a `Timing:` line sits at its comment's creation time, even if the comment was edited later;
- a `Timing:` line counts whoever wrote the comment;
- two pull requests sharing a head SHA share its runs, since GitHub's run record no longer names the pull request once it merges.

No GraphQL or run request changed, so the fixtures' answers stand. The original entry for [issue #262](https://github.com/melian-agent/melian/issues/262) now describes the summary in place of the stages.
