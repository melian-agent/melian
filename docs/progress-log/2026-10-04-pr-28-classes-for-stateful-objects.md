Melian's stateful objects became classes, as Pi Durable's are, in [pull request #28](https://github.com/melian-agent/melian/pull/28), closing [issue #27](https://github.com/melian-agent/melian/issues/27). Root `AGENTS.md` now states the rule, and [the decision](../decisions/2026-10-03-classes-for-stateful-objects.md) records it. The revision and worktree sources in core, the GitHub provider, Pi's credential store, and the review and publish harnesses were closures or object literals; each is now a class named after the thing, and every function callers used remains as a thin factory over it. The static runner's `Run` and the pattern engine's `Parser` and `Compiler` already followed the rule. Nothing changes behaviour: the tests pass with at most their construction changed.
