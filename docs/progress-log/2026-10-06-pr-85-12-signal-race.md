# Keep signal fixtures alive until SIGTERM

[Pull request #85](https://github.com/melian-agent/melian/pull/85), CI fix after the sixth pass.

CI failed the worktree signal regression on Node 24 and the revision regression on Node 22. A fast check-ignore child could exit before the parent sent SIGTERM. This is a fixture race, not a five-second test timeout.

The fixture starts real git check-ignore with --stdin and leaves its input open. It sends SIGTERM after the spawn event and checks the signal was delivered. Both source variants still require a real PID, signalCode SIGTERM and a typed unreadable error. No production change or design decision is needed.

A 100 ms parent pause after spawn reproduces both failures with the old arguments. The same pause passes both fixtures with open stdin. Restoring the fixture passes all twenty-four source-reader tests. The pause is only a local mutation probe.
