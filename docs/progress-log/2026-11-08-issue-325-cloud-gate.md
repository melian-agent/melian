[Issue #325](https://github.com/melian-agent/melian/issues/325) makes `npm run check` pass on a clean `main` in a Claude Code cloud session. One gate there, recorded on the issue, stopped at the release check, and with `GITHUB_TOKEN` unset failed 15 tests in four files. Five commits answer it, each from a test that failed at its head for the reported reason.

- 4dc05f24: `scripts/check-tools.mjs` asks again without a token GitHub refuses with HTTP 401, outside CI only. "asks again without a token GitHub refuses, outside CI only" failed before the fix with `HTTP 401`. Ten hand mutants of the new branch each failed that test alone, with and without a `GITHUB_TOKEN` in the environment. A first version passed `token: undefined`, which the default parameter turned into the container's own token, so one kill depended on the environment; the test passes `""` instead.
- 02684869: every isolated git environment in the tests sets `GIT_CONFIG_COUNT=0`, so the container's `url.insteadOf` entries no longer send the CLI tests' fake `git@github.com:` remote to GitHub. The 13 tests in `compare.test.ts` and `pull-request-stale-export.test.ts` failed in the recorded gate and pass after, 52 of 52.
- c8fb8370 and 669aa584: the questions-history check in `triage.test.ts` skips on a shallow clone, and the Enola spike's measurement skips without `/usr/bin/time`. Each prints its reason through `console.warn` and `context.skip`. With full history and `time` installed, both run and pass. A skip guard's mutants cannot fail a test: forcing or negating either guard turned a pass into a printed skip. Deleting a guard restores the recorded failure under its condition.
- ad2d0105: the real-process test counts a zombie as ended. The container's pid 1 leaves an exited orphan unreaped, so the supervisor stayed in `ps` and the test failed six runs of six alone; it passes six of six after. The file forbids mutation runs, since it signals real processes, so this change has none.

`AGENTS.md` now gives the container setup that runs the two skipped tests, and three learnings. `ProcessTable` itself still lists zombies; that costs `terminateRecorded` a one-second wait and a SIGKILL a zombie ignores, and is left for a ruling, since it is signal-sending code.
