For [pull request #296](https://github.com/melian-agent/melian/pull/296), Codex's adversarial review at `0904a938` found a third defect in a row in the code that judged a prober on its level's own tier. That code kept each judgement in a map keyed by lens and level. When two scoped variants ran at one level, the later variant overwrote the earlier one's refusal, so a prober outside `accept` left both records `ran`. The maintainer ruled on 2026-11-12, in the builder's session, that the class goes to the authority. `plan.mark` already judges every variant of a lens record, so a level-tier prober's model is now one more variant it judges, beside its planner's, and the map is gone (`7f233f5c`).

A test reproduces both orders of the two variants. Before the fix, the root's refused prober left both records `ran`, and the variant's refused prober failed both. After it, only the variant whose prober left `accept` fails.
