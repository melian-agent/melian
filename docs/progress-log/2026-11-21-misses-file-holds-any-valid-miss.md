# The misses file holds any valid miss

The evals guideline said the `MELIAN_EVAL_MISSES` file holds only `needs-execution` misses. The `whole` mode and the parity measurement review any valid miss a review of record found, such as an `owned-missed` one, so the sentence was wrong. It now says each entry is a valid miss Melian missed, that `lens` mode measures a miss one of whose rules `trust-boundary` declares, and that `whole` mode and the parity measurement measure any. The maintainer agreed the correction on 2026-11-21, in the coordinator's session.
