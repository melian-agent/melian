An Actions round now reviews the pull request with Melian built from its base commit, in fix pass 1 of [pull request #275](https://github.com/melian-agent/melian/pull/275), as the maintainer ruled. The job ran the head's own `melian`, and the comment trusted what it printed, so a head could change the CLI to print a clean verdict. Codex's adversarial review also showed that text prepended to genuine not-reviewed output made the comment say "passed". The round job now checks out the base commit, installs it, and runs `melian review "#N" --json` with that build, so the head is fetched as data and its code runs only where Melian runs it for a writer's head. The comment renders the verdict JSON alone, and reads a missing or malformed verdict, or one whose status disagrees with the exit code, as not reviewed. The text output goes to the job summary and the artefact only, and the text parsing in `scripts/round.mjs` is gone.
