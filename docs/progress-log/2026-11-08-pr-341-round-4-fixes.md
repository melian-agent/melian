# Pull request #341: round four fixes

[Pull request #341](https://github.com/melian-agent/melian/pull/341), for [issue #315](https://github.com/melian-agent/melian/issues/315), took three findings at `7c70d0f7`: one from Codex's adversarial review and two from Melian's round.

- `99704805` links a restatement only to the dismissal its verifier judged. Predecessor discovery showed the verifier a root's claim, but the link commit reread the root's current dismissal, so a maintainer who replaced it while the verifier ran got a link bound to a dismissal nobody compared. Each root now carries the identity hash round three added, `identityOf`, from discovery through `Restating` to `recordInheritances`, which links nothing when the identity has changed. That check replaces the commit's own test for a dismissed root with a recorded severity, since only such a root has an identity to carry.
- `ac203ee9` leaves an unchanged binary or `-diff` file unmapped. git gives an unchanged path no numstat entry, so such a file read as text and its empty hunk list became an identity map. `LineMap` now asks git whether the file is text, diffing it from the empty tree under the same attributes and pinned flags. The `-diff` test that inserted a line now leaves the file alone, and three more cover an unchanged NUL-holding file and both files mapped from a commit to itself.
- `0eae145b` asks that question at the older commit alone. An unchanged file is one blob at both commits, and a changed one has its own numstat entry, so the second diff added nothing a test could tell apart.
- `3694c22a` tests a text file that turns binary. After `0eae145b` every binary test started from a binary file, so the rerun of earlier claims found four mutants of the between-commits check surviving on their named test.

The pass enumerated 30 mutants over `7c70d0f7...0eae145b`, none omitted: 7 ignored by the Stryker configuration and 23 claimed, every one killed by its named test alone. It reran every earlier claim, 606 across four inventories, because a documentation change is no module Vitest tracks. 21 were superseded by lines this pass changed, and the four survivors above were killed by the new test.
