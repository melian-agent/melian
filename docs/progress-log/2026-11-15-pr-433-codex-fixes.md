Codex's adversarial review of [pull request #433](https://github.com/melian-agent/melian/pull/433) found three things, and the coordinator answered the two questions of approach on 2026-11-14. A cell too large to read back now fails `writeCell` before it reaches the remote, in f5a11944, proved by [its inventory](2026-11-15-pr-433-cell-size-mutants.json). A push that stops at its deadline no longer gives the landed check a second full deadline: the push gets three quarters of the time left and the check what remains, in bdbbc8de, proved by [its inventory](2026-11-15-pr-433-deadline-mutants.json). One very large file on the branch can still stall every call, because the fetch takes every blob of the tip. Only a writer can push one, so [the state-git guideline](../guidelines/state-git.md) records the limit, in 294fcacc, and [issue #446](https://github.com/melian-agent/melian/issues/446) holds the fix, a partial clone that needs git 2.44.
