# Step 14, doctor names the clone

`melian doctor` prints a `clone` line: the git clone the executable links to, its short commit, and whether its tree is clean. A dirty tree warns, since the review then ran edits no commit holds. A registry install under `node_modules` has no clone and prints nothing. This answers which Melian reviewed a change. Item 4 of step 14 in the [implementation plan](../design-implementation-plan.md); the CLI guideline lists the line.
