The round comment's length budget is now pinned on its own, in fix pass 1 of [pull request #275](https://github.com/melian-agent/melian/pull/275). The limit test took both its input and its expected bound from `maxLength`, so setting it to 100,000 still passed, and a comment past GitHub's 65,536 characters would fail to post. A new test pins the budget at 60,000 and holds a cut comment under 65,536.
