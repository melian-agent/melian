Round one on [pull request #527](https://github.com/melian-agent/melian/pull/527) blocked on its own queue check, in AGENTS.md's "Working in a cloud session". The check accepted any merge-group run whose branch named the pull request's number, and a run from an attempt the queue ejected stays in the Actions history under that name. So a builder could read an old run as proof that a new head was queued, and move on to the next issue. The check now lists only the runs created since the builder queued, and requires the group commit's second parent to be the pull request's current head, as the merge-group decision does. Both commands were tried on [pull request #499](https://github.com/melian-agent/melian/pull/499)'s queue run.
