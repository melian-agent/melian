[Pull request #310](https://github.com/melian-agent/melian/pull/310) shapes its lease as core's `Lease`, as [the coordination decision](../decisions/2026-11-08-how-melian-coordinates.md), which the maintainer adopted in [pull request #316](https://github.com/melian-agent/melian/pull/316), sets. `packages/core/src/lease.ts` holds the type: a holder, a run in a clone, a taken-at time, an expiry, and a fencing generation that rises with every taking. The state branch's `index.json` keeps each changeset's lease and the generation of its latest write; a push expires the lease rather than deleting it, so the generation survives, and lands only under the index's latest generation. The count of takings is now the generation. Each push's commit names the generation it was made under. The static checks' worktree lock and both publishers move onto the type in the two follow-ups the decision names.
