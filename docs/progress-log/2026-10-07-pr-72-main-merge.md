# Merge of main into the adjudication branch

[Pull request #72](https://github.com/melian-agent/melian/pull/72) took `main` after [pull request #68](https://github.com/melian-agent/melian/pull/68) landed. The importers, matching, bounded shapes and thread importer stay in their final form from #68, with `ComparisonError` and its codes in `errors.ts` again, because the adjudication module throws it and `comparison.ts` imports the adjudication schema; defined in `comparison.ts` it made the adjudication module fail to load first. The two new codes, `unknownFinding` and `invalidAdjudication`, sit beside the old ones. Five #68 tests now expect the `reviewers` an import stores. A mutation pass over every guard this branch adds, 298 in all, found 41 that no test failed under; each now has an assertion, five are equivalent mutants, and one branch of the export that no input could reach is gone.
