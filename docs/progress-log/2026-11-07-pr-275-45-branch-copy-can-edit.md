AGENTS.md and the builders decision now say that a branch copy of the round workflow can edit a round comment, in fix pass 9 of [pull request #275](https://github.com/melian-agent/melian/pull/275). Codex's adversarial review of 0584823 found that the documented condition, that the check holds while `melian-round.yml` is the only workflow with `pull-requests: write`, never held. A writer's branch copy of that same file, run with `--ref`, gets the permission through its own token, since the `melian-round` Environment withholds only the logins. The maintainer ruled to correct the docs and leave the fix to [issue #286](https://github.com/melian-agent/melian/issues/286). Until it lands, a comment that passes the check shows only which run it names, and a builder treats its findings as a writer's unverified text. This changes prose only; no test applies.
