# 2026-10-24: mutation evidence by enumeration and verification, designed

[Pull request #189](https://github.com/melian-agent/melian/pull/189) writes plan step 34's decision and design before any code, under the maintainer's rulings of 2026-10-24: Stryker leaves the hot path, `melian mutants verify` applies a mutant and runs the named test, enumeration and verification extend to any language and reach customers, and the `tests` lens uses both. It answers [issue #177](https://github.com/melian-agent/melian/issues/177) and designs the seam [issue #170](https://github.com/melian-agent/melian/issues/170) asks for.

**[Melian's flow]** [The decision](../decisions/2026-10-24-mutation-evidence-by-enumeration-and-verification.md) makes a verification record the evidence: a named test that passed unmutated and failed with a named mutant applied, at a named head. Three commands fold the two scripts into the CLI with a versioned inventory. A `MutationAdapter` lists, applies, names the test command and classifies, with the TypeScript adapter over the instrumenter and Vitest first and other tools behind `mutants.languages`. The `tests` lens receives the enumeration, probes under `budget.probes`, and backs each `untested-behaviour` finding with a surviving mutant. A record is evidence for its exact head only, chosen over re-verifying by import closure after measuring 72 to 328 mutants on four recent pull requests at about 3 seconds each under load. `static.mutation` stays as an opt-in audit. [The design](../design/mutation-evidence.md) summarises it, and the decision names what [pull request #185](https://github.com/melian-agent/melian/pull/185) must change.

**[Building Melian]** Melian's own tiers drop `static.mutation`; the host mutation-only run before a first round and the cold final run go. The decision lists each `AGENTS.md` line that changes once the step is built, and edits none now. The plan splits the build into four milestone 2 pull requests and two for milestone 3, with a golden that plants a stale kill across two heads.
