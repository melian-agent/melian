[Pull request #273](https://github.com/melian-agent/melian/pull/273) adds a `check (macos, 24)` job to `.github/workflows/check.yml`, for [issue #271](https://github.com/melian-agent/melian/issues/271). Linux skips every test that needs `sandbox-exec` or a BSD `ps`, so a macOS-only failure reached a pull request unseen until the coordinator reran the gate on a Mac. The job runs `npm run check` on `macos-latest` and then fails if any test in `scripts/codex-sandboxed.test.mjs` or `packages/pipeline/test/mutation-process-real.test.ts` did not pass, read from Vitest's JSON report. It sets `MELIAN_SANDBOX_NETWORK=1` and registers an ssh agent with launchd, so the registry and agent-socket tests run too. On its first run, at 96f3a78, the seatbelt suite passed 91 of 91 and the real-process suite 4 of 4, with 7,487 tests passed and 1 skipped across the whole gate; nothing needed a fix. The job took 23.5 minutes, 23 of them in `npm run check`. The Linux jobs on the same head took 8.3 minutes on Node 22, 13.2 on Node 24 and 12.7 on Node 26. AGENTS.md's loop and its `/private/var` learning named the job instead of a host rerun after a Codex pass; fix pass 1 restores the rerun. Making it required is the maintainer's choice, after a week of green runs.
