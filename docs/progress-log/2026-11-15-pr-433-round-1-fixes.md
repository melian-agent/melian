Melian's first own-build round on [pull request #433](https://github.com/melian-agent/melian/pull/433) blocked on six findings, and every one above advisory is now fixed.

- The handle's cache of judged entries was keyed by object ID and path alone. A blob that changed only its mode, or sat at an executable path beside a readable copy, borrowed the readable copy's judgement. An entry is now judged by its mode, type, object ID and path, in 70f39dc1, and the key is taken from the whole tree entry rather than a list of its fields, in 8908e0c8. [Its inventory](2026-11-15-pr-433-judgement-key-mutants.json) and [the key's](2026-11-15-pr-433-whole-entry-key-mutants.json) prove both.
- `melian doctor` read a relative `origin` against its own working directory, not the checkout's, in 57c626ba, proved by [its inventory](2026-11-15-pr-433-relative-origin-mutants.json).
- The record size limit had no test at the bound in UTF-8 bytes; 066522a6 adds one.
- A call could run past its deadline by a whole backoff, and a push given almost nothing still got a millisecond. Each call now holds one `Deadline`, a required argument of every git command, and no command or sleep starts once none is left, in 8e9369d8. 9fe50161 adds the test for creating the repository. [Its inventory](2026-11-15-pr-433-single-deadline-mutants.json) runs 126 mutants by hand: 125 killed by a named test, and one equivalent.
- Three sentences in the design and the CLI guideline ran past the writing rule's length, in c35dcb64, and internal TSDoc became line comments, in 22750b86.

Measuring how fast `records.git` grows, as the round asked, found it grew by the whole tip on every call: a fetch with `--depth` always asks the remote, and with no ref the remote sent everything again. One host writing 200 records reached 7.66 MB against the remote's 1.47 MB, and 50 reads of an unchanged branch added 1.99 MB. On the coordinator's answer of 2026-11-15, which was a choice of approach and not a ruling, each fetch now keeps `refs/melian/last` at the tip, in ff2c98b7 and e248ed8e. The same host then holds 1.48 MB, and an unchanged read receives nothing. [Its inventory](2026-11-15-pr-433-last-tip-hint-mutants.json) proves it. Nothing deletes old objects; [issue #451](https://github.com/melian-agent/melian/issues/451) tracks collecting them.
