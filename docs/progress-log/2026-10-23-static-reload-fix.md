# 2026-10-23: Stryker runs the tests that reload a module

[Pull request #186](https://github.com/melian-agent/melian/pull/186) closes the class [issue #169](https://github.com/melian-agent/melian/issues/169) investigated. Stryker passes the mutated file to Vitest's `related` filter, which keeps only test files whose static or literal dynamic imports reach it. `packages/pipeline/test/mutation-paths.test.ts` reached its module through `import type` and `vi.importActual`, so it never ran, and its 16 load-time mutants survived on unrelated tests.

AGENTS.md now allows a test to call `vi.resetModules()` and then `await import()` with a literal path, as a second exception to the rule against `await import()`, and [a decision](../decisions/2026-10-23-literal-import-in-reload-tests.md) records it. The learning added by [pull request #172](https://github.com/melian-agent/melian/pull/172) now gives the cause, and the interim dismissal rule is retired. `mutation-paths.test.ts`, the three live-entry tests and `thinking-task-migrations.test.ts` reload with literal imports; the live-entry tests drop the static import and empty mock they used as a workaround. `tool-cache.test.ts` keeps `vi.importActual`, which it uses inside mock factories, not to reload a module.

A static survivor's finding no longer tells the author to move a call that is already in the test. It names the covering test files from the report's `coveredBy` and `testFiles`, the first three and a count, says the `related` filter chose them, and says when the changed file's own test was not among them. [A decision](../decisions/2026-10-23-static-survivor-names-tests-that-ran.md) records it. The tests read a report recorded on the investigation's run.

The host's own check, run on a throwaway commit that touched the five survivor lines of `mutation-paths.ts`, left no survivor there. Its first full run found two survivors on the new report schema in `mutation.ts`, with the new advice naming the tests that ran; the refusal test now reloads the module, which kills them.
