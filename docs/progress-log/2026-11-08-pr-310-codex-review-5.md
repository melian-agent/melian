[Pull request #310](https://github.com/melian-agent/melian/pull/310), fixes for Codex's adversarial review of 1785bc4. Each began with a test that failed on 1785bc4 for the reported reason.

- A checkout pushed its lease before it read the branch's copy, so a copy it could not open, or a restore that failed, left a live lease holding every other clone off for two hours, behind a `LeaseHeld` that hid the cause. A checkout now opens every file of the copy under the key before it takes the lease, so nothing is pushed over a branch it cannot read, and a restore that fails after the lease expires that lease, fenced by its generation. `test/restore-failure.test.ts` fails the restore through `node:fs/promises`, since this container runs as root and ignores read-only directories.
- Core's `git` wrote standard input with no error handler, so git exiting before it read a large input ended the process with `EPIPE`. The pipe's error is now ignored, and git's exit code reports the failure.
