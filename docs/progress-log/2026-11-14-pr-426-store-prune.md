[Pull request #426](https://github.com/melian-agent/melian/pull/426) adds `melian store prune`, for [issue #348](https://github.com/melian-agent/melian/issues/348): a dry run that lists the rebuildable cache in a clone's state directory past its retention, with each entry's size and the space it frees, and with `--apply` removes it. [The retention decision](../decisions/2026-11-14-store-retention.md) records the maintainer's ruling of 2026-11-14 that changeset files wait for the shared record, so prune removes only cache: graphs older than seven days whose tree no branch, remote-tracking ref or worktree `HEAD` holds, with their coverage; graph directories with no readable entry after a day; coverage whose graph is gone; and mutation partitions untouched for fourteen days. It keeps every tool entry, since the tool-cache decision defers their pruning. It keeps changeset files, `scripted/` and every name it does not recognise, and removes nothing beside a live static check. `StorePrune` in the pipeline holds the plan and the removal, and the [pipeline guideline](../guidelines/pipeline.md#pruning-the-store) and [CLI guideline](../guidelines/cli.md) describe them.
