[Pull request #426](https://github.com/melian-agent/melian/pull/426) adds `melian store prune`, for [issue #348](https://github.com/melian-agent/melian/issues/348): a dry run that lists the rebuildable cache in a clone's state directory past its retention, with each entry's size and the space it frees, and with `--apply` removes it. [The retention decision](../decisions/2026-11-14-store-retention.md) records the maintainer's ruling of 2026-11-14 that changeset files wait for the shared record, so prune removes only cache: graphs older than seven days whose tree no branch, remote-tracking ref or worktree `HEAD` holds, with their coverage; graph directories with no readable entry after a day; coverage whose graph is gone; and mutation partitions untouched for fourteen days. It keeps every tool entry, since the tool-cache decision defers their pruning. It keeps changeset files, `scripted/` and every name it does not recognise, and removes nothing beside a live static check. `StorePrune` in the pipeline holds the plan and the removal, and the [pipeline guideline](../guidelines/pipeline.md#pruning-the-store) and [CLI guideline](../guidelines/cli.md) describe them.

The mutation inventory, [2026-11-14-pr-426-mutants.json](2026-11-14-pr-426-mutants.json), claims every row in `packages/pipeline/src/store-prune.ts` and `packages/cli/src/main.ts`, its `claimsIn` files, and `packages/cli/src/store.ts`'s dry-run line, the `--apply` guard's other half. Each of its 357 kills ran against its named test alone, which passed unmutated first and failed mutated: 339 by a test that already held, and 18 by a test written for a survivor. Two, in the catch that rethrows a refused read of a graph's entry, ran as an unprivileged user, since root reads a mode-0 file. Four claims are equivalent with a reason, and 76 are string literals Stryker's configuration leaves ungenerated. The rest of `store.ts` is CLI wiring and owes no claim, by the coordinator's scoping on [issue #348](https://github.com/melian-agent/melian/issues/348). `packages/pipeline/src/cache-scratch.ts` has no mutants: the enumerator leaves it unmutated because it sends signals. Codex's adversarial review found that `apply` acts on its plan without reading refs or graph entries again; the decision's section 3 now names the three races that leaves, each costing a rebuild, and a test holds that prune removes no changeset file or unrecognised name, whatever changes after the plan.
