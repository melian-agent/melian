# Builders ask the coordinator first

The maintainer ruled on 2026-11-13, in the coordinator's session, that a builder takes a question to the coordinator first and to the maintainer when the coordinator is not there to decide, and that every question is explained simply, as to a reader without the earlier context. `AGENTS.md`'s Work from issues section and [the decision](../decisions/2026-11-13-builders-ask-the-coordinator-first.md) carry the rule. Guidance only; no code changed.
