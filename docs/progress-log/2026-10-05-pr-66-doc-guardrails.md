[Pull request #66](https://github.com/melian-agent/melian/pull/66) turns two findings that Melian's own reviews raised five or more times into guardrails, as `AGENTS.md` asks of a repeated finding. `bare-issue-reference` flags a bare issue or pull request number in a Markdown file, and `overlong-sentence` flags 45 or more words with no sentence-ending mark on one line in `docs/`, the comparison records, and `README.md`. Both are `P3` and advisory, and both skip the golden corpus, and the first skips `.github/` too. The engine has no lookaround, so `bare-issue-reference` cannot tell link text from prose. A number that sits inside the text of a longer link fires, and a number after a quote mark or a backtick does not. A `forbidden-patterns` rule can now set its own `severity`, since the guardrail's `P2` would have made both ask for acknowledgement; a line several rules match takes the strictest. Each rule has a scripted golden, and `runGolden` now runs the guardrails for a golden that expects a `guardrail/` rule. Tests in `packages/core/test/doc-guardrails.test.ts` hold each pattern to a bare mention, to lines of the comparison records and progress-log entries that link correctly, and, for the sentence rule, to a 60-word sentence and a 24-word one.
