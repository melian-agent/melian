- `beb4ac14`: a run belongs to the pull request by commit, never by branch name. - `53e31b50`: every table cell goes through the one sanitiser, the event column included. Before the fix, a workflow name holding a newline, an ESC sequence and a pipe printed raw in the event column.

The maintainer accepted three limits, recorded in `scripts/timeline.mjs` with no code change:

- commits a force-push replaced appear only as the force-push row's tips;
- a `Timing:` line sits at its comment's creation time, even if the comment was edited later;
- a pull request closing several issues reads the first issue's ready and claim.
