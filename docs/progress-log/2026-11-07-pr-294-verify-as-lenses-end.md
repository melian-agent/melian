[Pull request #294](https://github.com/melian-agent/melian/pull/294) closes [issue #253](https://github.com/melian-agent/melian/issues/253): verification now starts as each lens ends, not after the slowest. The lens task records each lens's end in `melian.verification-waves`, and the review starts a wave of verification over the defects the ended lenses form while the others still run. A defect a later lens joins is verified again with every sighting, and that last verification decides it, as [the decision](../decisions/2026-11-07-verify-as-each-lens-ends.md) records from the maintainer's ruling. The final step keeps the reuse identity and copies every wave outcome whose candidate it still holds. The verification task is version 3, with a reopen test from main's own version-2 input. A scripted round's stage telemetry shows the verifier starting before the last lens ends. The saving against a live round is not yet measured: this branch's builder has no provider credentials, so the first live round of the review loop records it here, against the 35 to 50 seconds the issue's spans predict.
