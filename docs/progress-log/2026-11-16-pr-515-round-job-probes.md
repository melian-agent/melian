The round job installs bubblewrap, socat and ripgrep, and lifts the runner's AppArmor limit on unprivileged user namespaces. Before any step holds a login, `scripts/round-probe-containment.mjs` runs one probe through the real `Probe` class. It plants a canary under the round's login names, in the home and temporary directories and in a System V segment, then tries every route out: the environment, the command line, each readable file, writes, TCP, DNS, both proxies, `sudo` and IPC. It fails the round unless each is shut. `check.yml` runs the same script, so a change that opens a route fails CI first. The first runs found System V IPC open, so `packages/pipeline/src/probe.ts` now starts bubblewrap under `unshare --user --ipc`.

The round passes `--require-probes`.
