[Pull request #48](https://github.com/melian-agent/melian/pull/48) closes the gap [#42](https://github.com/melian-agent/melian/pull/42) left in the rule that no `melian.yaml` switches off the review of itself. A nested one was judged under the configuration of the directory above it, but the root's has none, so it was judged under its own settings, and a root that switched policy-change-review off hid every edit to itself. `policyChanges` now judges the root `melian.yaml` under the built-in defaults, so a change to it always raises the notice at `P2`, while what it sets still governs every path beneath it. [The decision](../decisions/2026-10-05-root-policy-file-under-defaults.md) records the choice.
