[Pull request #310](https://github.com/melian-agent/melian/pull/310), fix for Codex's adversarial review of 3e1df8b. A fetched branch whose `index.json` committed to no key read as a branch before its first push, so a clone holding another key could take a lease on it and write its own commitment, after which no clone could read the changesets already stored. Only a branch with no tip now lacks a commitment; any other is `invalidBranch`. `refuses an existing branch whose index commits to no key` failed first on 3e1df8b.
