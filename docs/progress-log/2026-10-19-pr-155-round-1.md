# Round 1 fixes on pull request #155

The first full Melian round on [pull request #155](https://github.com/melian-agent/melian/pull/155) raised two findings fixed here.

- `a21439815c77f407`. A finding can have two owed threads from one head. For example, F is posted in T1, a human resolves T1 while its edit is owed, and F returns in T2 at the same head. A changed dismissal reason then tied in `redismissed`'s sort by head, and could reach T1. The sort now breaks the tie by the root comment ID, which GitHub only increases. The regression test failed on `c3273a44`, with the reply sent to `1002`, and passes after the fix.
- `dcb45302ed287608`. After roots were tied to their review, no test failed when replies were read as roots. A new test proves that a reply carrying a signed finding marker never becomes a root, even when its own root is gone.

The different-login dismissal reply, `aec53abd`, belongs to [issue #154](https://github.com/melian-agent/melian/issues/154) and is left for the maintainer.
