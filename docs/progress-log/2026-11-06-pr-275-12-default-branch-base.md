The `melian round` gate now refuses a pull request whose base is not the default branch, in fix pass 2 of [pull request #275](https://github.com/melian-agent/melian/pull/275). Melian's round on `1f889e2` found that running the default branch's Melian does not pin the policy: `melian review "#N"` reads `melian.yaml` and every lens from the pull request's base, so a pull request into another writer's unmerged branch could carry a policy that runs no checks and get a clean comment. The maintainer chose to refuse such a pull request; [the decision](../decisions/2026-11-06-actions-rounds-run-default-branch-code.md) now says so. No local test can dispatch the gate; a dispatched run stands in.
