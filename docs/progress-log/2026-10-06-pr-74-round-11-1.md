The eleventh review of [pull request #74](https://github.com/melian-agent/melian/pull/74) found that a task could rename a Codex runtime directory into an auth temporary and replace it with a symlink. Runtime allowances now cover children only. The profile denies symlink creation under Codex’s home. The wrapper rejects symlinked runtime paths, auth.json, and the home itself before writing a profile. Tests cover rejection, blocked directory changes, and permitted child writes.

macOS refuses nested sandbox-exec with “sandbox_apply: Operation not permitted” when this suite runs inside the wrapper. The harness probes that capability and skips execution tests where it is unavailable. Profile tests still run. Expected regex paths now escape the whole temp path, whose wrapper-created parent contains a dot.
