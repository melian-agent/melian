[Pull request #43](https://github.com/melian-agent/melian/pull/43) writes the convention the maintainer asked for into AGENTS.md as a rule a lens can quote: behaviour belongs to the object it is about, so a function whose first parameter is a domain object is a method of that class. The root `melian.yaml` gains the `free-domain-function` guardrail, which holds new code to the rule from the next review of Melian's own pull requests, with the eleven files that break it today grandfathered until [step 12](../design-implementation-plan.md) refactors core's domain types into classes. [decisions/2026-10-04-domain-objects-carry-behaviour.md](../decisions/2026-10-04-domain-objects-carry-behaviour.md) supersedes the class convention.
