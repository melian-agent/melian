[Pull request #16](https://github.com/melian-agent/melian/pull/16)'s default tiers name only checks that ship: `fast` runs guardrails and static tools, `standard` adds the correctness lens, and `full` adds the contracts lens. The defaults had named `lens.security` and `lens.conventions`, which do not exist, so once the tier became the manifest every default review read not reviewed. A test now fails if a default names a check that is neither a built-in lens nor a deterministic check.
