[Pull request #314](https://github.com/melian-agent/melian/pull/314), fix for Codex's adversarial review of 26338cc. With no writers' key, or with `melian/state` out of reach, `publish` used this clone's copy, which may lack a newer round another clone pushed for the same head, so it could post a stale passing verdict over a newer blocking status. The maintainer ruled that `publish` refuse unless it leased the branch. `ChangesetStore.write` takes `authoritative`, which refuses an unreached checkout before any GitHub call, and `publish` passes it. The refusal tests for no key and for an unreachable branch, and the test that `publish` asks for an authoritative store, failed first on 26338cc.
