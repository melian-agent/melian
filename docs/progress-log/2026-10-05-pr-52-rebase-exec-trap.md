[Pull request #52](https://github.com/melian-agent/melian/pull/52) records two learnings in AGENTS.md from the step 12 refactor. Gating commits with `git rebase --exec` leaks `GIT_DIR` into the test suite's git commands and corrupts the real repository, so commits are gated in a throwaway worktree with `GIT_*` unset. The Biome rule's exclusion list is meant to stay empty, which [pull request #51](https://github.com/melian-agent/melian/pull/51) achieves, so a file joins it only with a decision that says why.
