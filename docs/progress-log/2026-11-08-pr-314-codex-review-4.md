[Pull request #314](https://github.com/melian-agent/melian/pull/314), fix for Codex's review of ff4b2e1, on the fenced lease of [the coordination decision](../decisions/2026-11-08-how-melian-coordinates.md). A clone with SQLite storage from before the state branch checked once that `melian/state` did not hold the pull request, then published with no lease, so another clone that stored a newer round after the check went unnoticed. `StateBranch.reserve` now takes the pull request's lease without storing a copy and refuses a pull request the branch holds; `StateReservation.confirm` renews it before posting and is refused once another run took it, at a higher generation, or stored the pull request; `release` expires it. A legacy `publish` holds a reservation through `ChangesetStore`, and needs the writers' key, as any `publish` does. The race test, the lease test and the no-key test failed first on ff4b2e1.
