A test now runs the gate's pull request step of the `melian round` workflow, in fix pass 3 of [pull request #275](https://github.com/melian-agent/melian/pull/275). Melian's round on 1aff2d1 found that nothing tested the refusal of a fork's head. Its verifier refuted the danger, since the pusher check would still refuse an outsider, but held it for a maintainer. The test runs the step's own shell against a fake `gh` that answers only the request for the pull request. It covers an open pull request from this repository, a fork's head, a deleted head repository, a closed pull request, a base other than the default branch, an unknown default branch, and an unreadable head or base SHA. Removing each guard in turn, seven hand mutants, fails it. No defect was reported, so no test failed first.
