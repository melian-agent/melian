The check request now keys Melian's own check code by hash, not by the hand-raised `checkVersions`, as the maintainer ruled on 2026-11-16 on [issue #437](https://github.com/melian-agent/melian/issues/437). `scripts/code-hashes.mjs` gains the `checks` producer, whose entry `packages/pipeline/src/checks.ts` reaches 102 modules, and the request holds `codeVersion("checks")` as `code`. `writesFixedText` takes any request holding a 64-digit `code` as one whose static checks store no tool text, and judges a stored request without `code` by its numbers as before. Every stored check run misses once, at no token cost. [The decision](../decisions/2026-11-20-check-code-from-recorded-hashes.md) records it; the model producers follow in a second pull request.
