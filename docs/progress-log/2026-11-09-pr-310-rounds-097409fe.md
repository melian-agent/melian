[Pull request #310](https://github.com/melian-agent/melian/pull/310), fixes for the Actions round on 097409fe, [run 42529237499](https://github.com/melian-agent/melian/actions/runs/42529237499), and an own-build round run in the builder's session, under the maintainer's rulings of 2026-11-08.

- P1, hooks: state-branch git commands ran the clone's hooks, which a head can supply through `core.hooksPath`, with the review's environment and its credentials. Every state-git git command now runs with `core.hooksPath=/dev/null`, and core's `gitOutput` and `gitOutputBytes` take options so the read commands carry it too. `runs no hook of the clone's, which a head can supply, while it fetches, pushes or moves a ref` failed first on 097409fe, with `pre-push` and `reference-transaction` both run. Leaving the key out of the count, or `update-ref` without the environment, fails it; an empty path is equivalent, since git then finds no hooks either.
- P1, the holder label: a live lease of the caller's own `holder` label was taken over as a crashed run's, though another copies directory, under another copy lock, could give the same label. As the maintainer ruled, the branch mints the clone's identity itself: an unguessable ID in the copies directory's `holder` file, written owner-only, which the CLI already kept there. A lease names its clone by the label and that ID, so the label is now 1 to 163 characters. `refuses a live lease to a branch of another copies directory, though its label is the same` and `keeps one identity for a copies directory across branches, so a crashed run's lease is taken over` failed first on 097409fe; `refuses a copies directory whose clone ID was damaged, rather than mint another` covers the guard. Judging by the label, accepting any ID, a readable ID file, or dropping the ID from the lease each fails a named test. Eight older tests named the clone by its label alone, or listed the copies directory without the ID file; each now matches the label and ID, and the label bound moved from 200 to 163.
