That threshold is a reading of the maintainer's "if important", and he may adjust it. The decision states the cost: a file that writes its own table overrides a lens's declared default unless it restates it. `melian doctor` lists each such override, and `melian findings` names the file and entry that decided. The same commit adds a `preExisting` key, the cap on pre-existing findings by severity, `advisory` by default. It layers key by key, apart from the walk, so a folder's table does not erase it.
