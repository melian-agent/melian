The contracts lens keeps to declared contracts, in [pull request #20](https://github.com/melian-agent/melian/pull/20), after the [second live run](../../packages/evals/runs/2026-10-03-live-goldens-2.md) showed it reporting body bugs at their callers. `changed-return` and `changed-error` described runtime behaviour, which any body bug changes, so the model read a broken body as a changed contract. They now name the return shape and errors written in a function's declaration, its types, or its documentation, and the body tells contracts to drop a defect whose fix belongs inside the changed function's body. `contracts-breaking-signature` now also expects the defect correctness found there: `formatPrice` accepts any currency but still divides by 100, so 500 yen renders as "JPY 5". The evals guideline asks a golden for its declared defects rather than exactly one.
