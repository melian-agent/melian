Build 2 of step 46, [issue #393](https://github.com/melian-agent/melian/issues/393), is [pull request #433](https://github.com/melian-agent/melian/pull/433). It replaces the lease and sealing of [pull request #310](https://github.com/melian-agent/melian/pull/310) with `GitRecordStore`, which keeps the shared record on `melian/state` and passes core's conformance suite on a real bare repository. It fetches the branch's tip alone into a bare repository of its own, checks that repository's configuration before every git command, and pushes one commit per write with a lease on the tip it read. A push stopped at its deadline counts as landed only when its commit is the tip or an ancestor of it. By [the amending decision](../decisions/2026-11-14-git-record-store-refuses-by-location.md), a file Melian did not write refuses its own changeset when it sits in that changeset's folder, and every changeset otherwise; `melian doctor` names such files. The mutation proof is [the inventory](2026-11-14-issue-393-mutants.json): 832 mutants, 507 killed by the first tests, 109 by tests added for them, and 216 equivalent, 178 of them string literals Stryker does not generate.
