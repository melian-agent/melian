The macOS tests now run beside CI's Linux jobs, not after them, for [issue #599](https://github.com/melian-agent/melian/issues/599), as the maintainer ruled on 2026-11-20 ([the decision](../decisions/2026-11-20-macos-tests-run-beside-linux.md)). `test (macos, 24)` runs the files `scripts/macos-tests.json` lists, so it no longer waits for the Linux report. Of `packages/pipeline/test/probing-level.test.ts` it runs only the twelve tests tagged `macos`, which took 24 seconds on 4 cores, against 114 for the whole file. `check (macos, 24)` keeps its name and runs `scripts/compare-platform-reports.mjs` over the two jobs' reports. It makes the four checks the macOS job made before, and a fifth: every file Linux skipped a test in is on the list. `scripts/compare-platform-reports.test.mjs` proves each check over reports it builds. [The run record](../research/2026-11-18-ci-runner-sizes.md#measured-afterwards) gains the measured times of the 16 vCPU change, which saved about a minute a run, not 7.8.
