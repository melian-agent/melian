Two learnings join the end of `AGENTS.md`. The first is that decision files, progress-log entries and pull request descriptions must not say a finding is accepted, by design or not to be reported, since a lens reads that as steering the reviewer; it cost a dismissal each round on three pull requests, [pull request #492](https://github.com/melian-agent/melian/pull/492) among them. The second is that a process's start time printed by `ps -o lstart` is display text, so it must never decide whether two processes are the same; it came up designing the sweep for [issue #460](https://github.com/melian-agent/melian/issues/460).
