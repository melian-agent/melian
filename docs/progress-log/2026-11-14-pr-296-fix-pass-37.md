For [pull request #296](https://github.com/melian-agent/melian/pull/296), fix pass 37 stops a replaced review from deciding a verdict. Codex's adversarial review and the Opus review of record found it at `2ed4426e`, each by a different path.

- **A review whose lens task another replaced records no verdict** (`3fa965be`). Pass 36 lets a repeat review replace a finished probing run under the same selection, and that commit clears the run's findings. The review it replaced, still running, then read no candidates, skipped the rerun task's ownership check and adjudicated, since adjudication compared only the selection. It stored `passed` over a blocking finding. The new test in `test/probing-level.test.ts` starts the repeat review once the first review's lens task has finished: at `8ac56a0c` it read `expected undefined to match object { code: 'superseded' }`, with the first review's verdict `passed` and no findings, and it passes after the fix. The review of record's probe, where the stale review instead overwrites the newer `passed` with `not reviewed`, now leaves `passed` standing and ends the stale review `superseded`.
- **The task check replaces the selection check** (`0b38f74e`). An entry whose selection differs always names another lens task, or none, so the comparison of selections could go. A review a `--rerun` replaced now ends `superseded` rather than `lensFailed`, as the guard's own comment always said; `test/review.test.ts` changes that one assertion.
- **Tests for the rest of the guard** (`5325e237`): a review that runs no lens after a lens review of the head, and a review whose index entry is gone.

This closes part of [issue #350](https://github.com/melian-agent/melian/issues/350): adjudication now refuses a review that no longer owns its lens task. It does not check the verification task, and it adds no shared ownership predicate, which #350 asks for. [Issue #381](https://github.com/melian-agent/melian/issues/381) stays open: a replaced review can still start or replace a verification, though it can no longer adjudicate from it.
