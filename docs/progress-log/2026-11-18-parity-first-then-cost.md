# Parity first, then cost

[Parity first, then cost](../decisions/2026-11-18-parity-first-then-cost.md) records the maintainer's ruling of 2026-11-18. Melian first finds what the review of record finds, at about the cost of a review of record and Codex's review together. It optimises cost after parity is shown.

It changes no committed budget, level or route. [Issue #561](https://github.com/melian-agent/melian/issues/561) measures a parity arm against the committed arm, and a later pull request changes the policy once that run record is in. Related: [issue #559](https://github.com/melian-agent/melian/issues/559) and [issue #555](https://github.com/melian-agent/melian/issues/555).

`docs/design.md` gains one goal that links the decision.
