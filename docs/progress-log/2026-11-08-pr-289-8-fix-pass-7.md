Fix pass 7 for [pull request #289](https://github.com/melian-agent/melian/pull/289) closed round seven's finding 0d6696cab532271f: a probe read a reviewer's untracked `.npmrc`, because it was granted the whole working tree with a short deny list. The maintainer ruled on 2026-11-08 that a probe reads the head's tracked tree only, plus an allowlist, after an attacking review showed why a per-file grant cannot work. [The decision](../decisions/2026-11-07-probes-run-under-sandbox-runtime.md) now records the rule, the mechanism and the three rulings.

`Probe` takes a head, a checkout and a commit, in place of a worktree and an install. It writes the commit's tree into its scratch from a temporary repository that borrows the checkout's objects, with no user or system git configuration and attributes that turn every filter and conversion off, and runs the probe there. The root policy's new `probe.read`, read from the base, names what else a probe gets: `node_modules`, the default, links the install in, and any other relative path inside the checkout is copied in when the probe opens. `Probe` refuses an absolute path, a `..` segment, the checkout itself, and a path that resolves outside it. `.npmrc`, `.env*` and `.git` are denied at any depth in the tree and the install, and so is npm's builtin `npmrc`. `melian probe` passes `HEAD` and the allowlist of the first of `origin/HEAD`, `origin/main` and `main` that resolves.

The install is linked by the same `linkDependencies` the static checks use. It moved from `static.ts` into its own module, `packages/pipeline/src/link-dependencies.ts`, which holds no signal code, so its mutants are enumerated; `static.ts` keeps a wrapper that turns a failure into its `CheckError` and adds the lockfile note, and passes its own `shell`, so its timeout and error codes are unchanged.

Every new test failed at 358ada2a for its reason: an untracked `.npmrc`, a modified tracked file read as modified, a staged file, a file written after the probe opened, a nested repository's `.git/config`, an `.npmrc` inside the install, a smudge filter's output, an allowed path read live rather than copied, four allowlist entries accepted that the rule refuses, and the CLI following the head's own `probe.read`. All pass after the fix.
