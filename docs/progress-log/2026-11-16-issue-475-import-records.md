A review that names a record store, under a base that sets `trust.writers: true`, now reads the changeset's records before anything runs, for [issue #475](https://github.com/melian-agent/melian/issues/475). `ImportedRecords` counts the records of the changeset whose kinds a producer asks, sets aside a payload of a later version, and fails the set on a known version whose payload breaks its shape. Checks, verification, triage and the walkthrough each stand on a record that answers their own request, and run when none does, or when two records under one key disagree. [The import decision](../decisions/2026-11-16-a-review-resumes-from-imported-records.md) records the rules, amends rule 4 of the shared record decision for disagreeing records, and says what a writer of the store can make a review skip, a triage `skip` among them.

A host exports the record it stood on byte for byte, so its round's `read` names the same verification as the first host's, and a second clone's round reads a check record the first never wrote. Imported dismissals are not applied; that is [issue #506](https://github.com/melian-agent/melian/issues/506). The lens run's import follows in this pull request.

Each guard of the new code has a test that fails when it is removed, run by hand: the triage import and its chosen-option check; the walkthrough import, its rerun exception, its route check and its export; the CLI's import; and the match's key.
