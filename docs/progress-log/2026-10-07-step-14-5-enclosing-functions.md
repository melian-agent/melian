# Step 14, enclosing functions in the change prompt

At `reads: functions` the change prompt now carries the head's function around each hunk of a TypeScript file, in a `function` block after the diffs, found with the compiler's syntax tree through its synchronous API over a virtual file system of the head's text from git. The step 11 compiler graph is in the unmerged [pull request #89](https://github.com/melian-agent/melian/pull/89), so this branch reads the same API itself, and holds no other code of that graph. Another language, a function past 250 lines, a hunk outside any function, and anything past the bounds stay with the instruction, which now names them. A new [decision](../decisions/2026-10-07-enclosing-functions-in-the-change-prompt.md) supersedes the reading-scope decision.
