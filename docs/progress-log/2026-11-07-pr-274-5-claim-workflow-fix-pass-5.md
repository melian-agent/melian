Fix pass 5 on [pull request #274](https://github.com/melian-agent/melian/pull/274) is docs only. Codex's review of `d4a1bc9f` found that on an issue with more than 100 timeline events, an earlier comment deleted between two page fetches can move a writer's ready label onto a page the run already read. The run then misses the label and clears a valid in-progress label until the next comment's run puts it back. The maintainer accepted the race, and [the decision](../decisions/2026-11-05-claim-labels-by-workflow.md) now names it as a known limit, with the scenario and the repair: the next comment's run, and a builder who sees the label drop commenting again.
