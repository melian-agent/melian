# Lens prompts that converge

[Pull request #121](https://github.com/melian-agent/melian/pull/121) changes the lens prompts so a round sees a defect class at once. Every lens, Melian's `durability` included, reports each instance of a shape the change repeats as its own finding, and each names the class and cites the others ([decision](../decisions/2026-10-15-each-finding-names-its-shape.md)). A first version folded the instances into one finding; review showed that breaks identity, dismissal and verification. `trust-boundary` walks six probes for every host path an author can influence. `tests` gains `fake-answers-unasked`, the class of C1 in the [record for pull request #116](../../packages/evals/comparisons/2026-10-14-pr-116.md) ([decision](../decisions/2026-10-15-unasked-fakes-belong-to-tests.md)). Three goldens hold them: `correctness-repeated-shape`, `trust-boundary-joined-path-escape` and `tests-fake-answers-unasked`. Every lens's version changes. No design rule for a supersession that drops a clause: the deterministic supersession check another lane is planning owns it. Live passes over every lens's goldens are owed.
