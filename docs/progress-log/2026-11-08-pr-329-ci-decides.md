The maintainer accepted [the shallow-history amendment](../decisions/2026-11-08-shallow-history-skips-outside-ci.md) on 2026-11-08, in the coordinator session, as recorded on [pull request #329](https://github.com/melian-agent/melian/pull/329#issuecomment-6718154467). The ruling asked for a test where the `CI` variable alone decides between a skip and a failure. `shallowSkip` in `packages/evals/test/triage.test.ts` now holds the guard, and "skips a shallow clone's history only when CI is unset, and fails it under CI" builds a two-commit repository and its `--depth=1` clone. On that clone, an unset `CI` returns the skip reason, `CI=true` returns none, and the history walk throws `history is shallow`. The full repository never skips. Six hand mutants of the guard each failed that test alone: the `CI` operand removed or forced false, `||` made `&&`, the shallow comparison negated or forced, and the reason emptied. The test was written for the ruling, not from a defect, so it has no failing run before the change.
