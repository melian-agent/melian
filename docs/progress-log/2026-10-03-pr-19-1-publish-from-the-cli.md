Step 8 publishing from the CLI opened as [pull request #19](https://github.com/melian-agent/melian/pull/19), closing [issue #8](https://github.com/melian-agent/melian/issues/8), stacked on [pull request #16](https://github.com/melian-agent/melian/pull/16). `melian review` takes a range or a pull request and exits 0 passed, 1 blocking, 2 not reviewed, or 3 findings with none blocking; `melian publish` posts the stored review of a pull request's head as one commenting review with inline findings, replies in resolved threads, and a `melian/review` commit status; `melian findings` and `melian doctor` complete the command. Core holds the `ReviewProvider` port, `packages/github` implements it with Octokit, and the pipeline's publish task records every post in `PublishedDocument` and reads Melian's markers back, so a crash between a post and its record never posts twice. Check runs, comment commands, and cross-revision diffing beyond publication are left for later milestones.
