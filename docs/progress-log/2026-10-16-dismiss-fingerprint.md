# A dismissal survives a budget-only lens override

`melian dismiss` refused to decide a verdict again after an uncommitted lens file that raised a budget was removed, because the adjudication fingerprint listed lens variants by version and a version hashes the budget. The fingerprint now lists the declared resolution each lens report resolves through, so only a change that decides resolution refuses. Codex's review found the first attempt, which listed every variant, missed a report that fell through to a nearer lens; the second fix covers it. A models-only preference file never reached the fingerprint; a test now guards that too. The refusal named its remedy twice, and now names it once. [The decision](../decisions/2026-10-16-resolution-fingerprint-holds-resolution-only.md) records the choice.
