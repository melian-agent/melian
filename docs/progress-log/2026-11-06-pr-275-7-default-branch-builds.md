The `melian round` workflow now runs only from the default branch, and builds Melian and its helper scripts from that commit, in fix pass 2 of [pull request #275](https://github.com/melian-agent/melian/pull/275). Melian's round on fix pass 1 found that building from the pull request's base still let a writer choose the code that runs with the logins: a base can be another unmerged branch, and `--ref` can dispatch any branch's copy of the scripts. [The decision](../decisions/2026-11-06-actions-rounds-run-default-branch-code.md) records the maintainer's choice of the default branch over refusing pull requests based elsewhere. No local test can show a dispatch refused from another ref; a dispatched run stands in.
