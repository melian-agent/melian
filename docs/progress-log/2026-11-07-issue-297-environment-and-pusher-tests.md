Two follow-ups from the final round of [pull request #275](https://github.com/melian-agent/melian/pull/275), [issue #297](https://github.com/melian-agent/melian/issues/297). The `melian round` workflow's logins are kept from every other branch's copy of it by the `melian-round` Environment's branch policy, which lives in the repository's settings, so a removed policy would have let any branch deploy to it unseen. The gate now reads the Environment and its deployment branch policies before any job holds a login, and refuses unless the policy is custom and names the default branch alone, as a branch; a policy GitHub stored without a type counts as a branch. The gate job gains `actions: read` for the two reads. The pusher test's fake `gh` returned already-projected events whatever the `--jq` said, so reading `.payload.before` for the head passed every test. It now runs the workflow's own expression over raw event pages, with decoys a wrong projection would pick. Twelve hand mutants of the two steps are each killed by their named test alone: [2026-11-07-issue-297-mutants.json](2026-11-07-issue-297-mutants.json).
