Codex's review of [pull request #185](https://github.com/melian-agent/melian/pull/185) at `cd158f9e`, against main holding [pull request #189](https://github.com/melian-agent/melian/pull/189), found two gaps. A file unit is now covered for a lens only when the ledger shows the lens's input carried every field; each unit outside the diff cap gets a compact metadata block, and a content read covers no field. A reread of the whole decision against main's #189 found nothing else that disagrees.
