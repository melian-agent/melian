# Issue and pull request text is written simply, for a reader with no context

The maintainer ruled on 2026-11-14, in the coordinator's session, that any issue or pull request text must be expressed simply, for a human audience, with no assumed context. [The decision](../decisions/2026-11-14-issue-and-pull-request-text-assumes-no-context.md) records the rule, and the Writing rules in `AGENTS.md` carry it in one bullet.

Guidance only: no code or test changes.
