# trust-boundary-policy-from-head

Seeded from finding 10 of the [comparison record](../../comparisons/2026-10-03-pr-12.md) for [pull request #12](https://github.com/melian-agent/melian/pull/12): `loadConfig` read `melian.yaml` from the checkout, so a pull request's head set the policy of its own review. The golden keeps the read and the verdict in one file, `src/review.ts`, so the defect has one place to be reported: with the read in its own module, the lens reported it at the caller as often as at the read. The record's `loadConfig` read the checkout from the start; the golden recasts the defect as a change away from a base that read the policy from the base commit.
