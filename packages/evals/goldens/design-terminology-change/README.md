# design-terminology-change

Regression for the candidate-selection defect in [pull request #93](https://github.com/melian-agent/melian/pull/93). The head changes the terms and adds a conflicting decision without Supersedes. Base search finds the untouched old terms. The finding belongs on the new decision with base-text evidence. `src/publish.ts` is an accepted alternative location: the lens's rules name the new decision as the finding, but its cause is the decision line and the loosened function together, and live runs on Opus and Sol place the same `criterion-selection-bias` finding on either. A finding under another rule, such as `dropped-guard`, still costs precision.
