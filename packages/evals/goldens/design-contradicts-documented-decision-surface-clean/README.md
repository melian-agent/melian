# design-contradicts-documented-decision-surface-clean

A clean case for the per-surface rule. The base design says the ledger shows every diagnostic and the status shows its plain description alone. The head adds the round's diagnostic notes to the ledger, which that surface allows, and leaves the status line alone. The positive twin of this shape would add the notes to the status. A review must report nothing. The scripted run proves the plumbing only; whether a live lens stays quiet is a live measurement.
