# A resolution change in a nested melian.yaml whose parent switches the review off still draws a notice

A `resolution` change in a nested `melian.yaml` whose parent switches the review off still draws a notice at `acknowledge`. The root switches `policy-change-review` off and maps P2 to `silent`. The head lowers P1 in `services/melian.yaml`. The notice is reported all the same, and the floor holds it at `acknowledge`.
