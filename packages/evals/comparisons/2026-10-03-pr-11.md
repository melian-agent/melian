## Differences

Claude Code found eight, all about test robustness and portability. Codex found three, all at the design level. The sets overlap once, on the fake-model export: Claude Code raised it as public-API hygiene, Codex as part of whether the wrapper does what its guidance claims. Codex's crash-gap finding is the most consequential of the eleven and the only one that changes the design: it produced the rule that a tool with a durable side effect is an idempotent upsert marked replay-safe, or is guarded by a durable record. Both reviews ran against the same branch head, which did not change between them.

Each valid finding is a golden to be written for the evals corpus once step 5 of the [implementation plan](../../../docs/design-implementation-plan.md) defines the format.
