# Comparison review: [pull request #80](https://github.com/melian-agent/melian/pull/80)

Pull request: [melian-agent/melian#80](https://github.com/melian-agent/melian/pull/80), milestone 2's step 6, stacked on [pull request #62](https://github.com/melian-agent/melian/pull/62). It adds durable LLM verification between the shared merge and adjudication. A verifier judges each original lens claim as `confirmed`, `plausible`, or `refuted`, with a reason and optional correction. It reads evidence back before accepting a refutation. Only refuting every lens claim can remove a lens-only defect; deterministic proof remains. Unjudged lens findings are capped at advisory, and a failed verifier leaves the review not reviewed.

The change routes the verifier across model families, stores judgements beside sightings, and renders verdicts and corrections in terminal and GitHub output. It adds six scripted verifier cases: four execution-dependent misses and two decoys. Decision-model verification, calibrated confidence, Enola callers, and code execution by the verifier remain deferred.
