# Comparison review: [Pull request #125](https://github.com/melian-agent/melian/pull/125)

[Pull request #125](https://github.com/melian-agent/melian/pull/125) is milestone 2 step 22, incremental mutation. The `static.mutation` check keeps Stryker's incremental file per review target, base, base policy and installation. A later head reruns only what changed since the last judged head, instead of every mutant. It merged at `09874751` from head `6a6035a3`.

The maintainer's ruling on 2026-10-15 shaped the final design, after four rounds had each found another way a reused kill goes stale: "Reuse while iterating, final run cold." A run that was handed an earlier head's results is now `provisional`: its findings count, but the review reads not reviewed, the published status is `error`, and only a run from nothing, `melian review --cold`, can approve. The checks document rose to version 4, the verdicts document to version 9, and `provisional` became a check status. After round eight the coordinator escalated the class, as the Converging rules ask, and rounds seven to twelve all ran cold.

Letters identify reviewers. A is Codex's adversarial review, which did not run. B is the Claude Opus 5.5 review of record at `de8e8e74`, with its re-check at `84f59127`. R1 to R12 are Melian's twelve rounds, at `65e63a0b`, `ed9b991e`, `c9fdef19`, `57e0a755`, `6609de8e`, `7fe9120d`, `d40cb479`, `67448237`, `0d1dac62`, `de8e8e74`, `84f59127` and `6a6035a3`, where rounds seven to twelve ran with `--cold`.
